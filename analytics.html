Analytics

This page shows aggregate search analytics collected by the app. It is a lightweight dashboard summary for internal use.

What is tracked

  • SKU search strings and counts (no personal data).
  • Timestamp of searches for simple trend charts.

Viewing data

The admin panel exposes charts built from the search_log table and a view named search_counts. If the view is missing, analytics pages will report unavailable data and the admin will fallback to simple counts.
