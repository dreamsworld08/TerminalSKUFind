Privacy

This site and the web app use Supabase for data storage. The public client uses a Supabase anon key for read operations and simple admin actions. Do not store sensitive secrets in the client code or public repo.

What is collected

  • Searches: lightweight search logs (SKU strings) for analytics and popularity charts.
  • Optional admin inputs when using the admin panel.

How data is used

Search logs are aggregated to build popularity dashboards. No personal user-identifying data is collected by default.

Contact

For concerns, open an issue or contact the repository owner.
